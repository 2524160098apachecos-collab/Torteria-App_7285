# Evidencias para la entrega

Realiza una captura de navegador y otra de Postman por cada endpoint:

1. `GET http://localhost:8080/clientes?id=2`
2. `GET http://localhost:8080/torta?id=3`
3. `GET http://localhost:8080/pedido?id=1`

En Postman muestra URL, metodo GET, respuesta JSON y estado HTTP `200 OK`.
Incluye las seis capturas en el Word de evidencias y exportalo a PDF.
